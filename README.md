# Тимчасовий аукціон

Сторінка для учасників: `https://<ваш-логін>.github.io/<назва-репозиторію>/`
Адмін-панель: та сама адреса + `admin.html`

Сайт статичний, збірка не потрібна, тож його можна викласти на GitHub Pages. Ставки, лоти й учасники зберігаються в безкоштовній базі **Firebase Firestore**. Правила безпеки (`firestore.rules`) перевіряє сервер Firebase, тому ставку не вийде підробити через браузер.

## Налаштування (≈10 хвилин, один раз)

1. Відкрийте https://console.firebase.google.com → **Add project** (Google Analytics можна вимкнути). Тарифу Spark (безкоштовного) достатньо.
2. **Build → Firestore Database → Create database** → режим *Production*, регіон `eur3 (europe-west)`.
3. **Build → Authentication → Get started**, на вкладці *Sign-in method* увімкніть:
   - **Anonymous** (так учасники отримують анонімний ідентифікатор без реєстрації пошти);
   - **Email/Password**.
4. **Authentication → Users → Add user** — створіть адміністратора (ваша пошта + пароль).
5. **Firestore → Rules**: вставте вміст файлу `firestore.rules`, замініть `admin@example.com` на пошту адміністратора і натисніть **Publish**.
6. **Project settings (шестерня) → General → Your apps → Web (`</>`)** → зареєструйте застосунок і скопіюйте об'єкт `firebaseConfig` у `config.js` → `firebase`.
7. У `config.js` впишіть ту саму пошту в `adminEmails`.
8. **Authentication → Settings → Authorized domains**: додайте домен сайту, наприклад `<ваш-логін>.github.io`.
9. Увімкніть публікацію: репозиторій на GitHub → **Settings → Pages → Deploy from a branch → `main`, папка `/ (root)`**.
10. Залийте зміни на GitHub, відкрийте `admin.html`, увійдіть і додайте лоти.

> Ключ `apiKey` у `config.js` не є секретом: доступ до даних обмежують правила з `firestore.rules`.

## Як працює захист від накручування

- **Реєстрація**: ім'я та номер телефону, а також згода, що ставка — це зобов'язання купити лот. Повний номер бачить лише адміністратор, інші учасники бачать ім'я та дві останні цифри.
- **Мінімальний крок**: нова ставка ≥ поточна + крок.
- **Максимальне підвищення за раз**: не можна одним кліком підняти ціну в рази.
- **Не можна перебити власну ставку**, поки вона лідирує.
- **Пауза між ставками** одного учасника (10 с).
- **Ставку не можна скасувати чи змінити**: це може лише адміністратор. Тому в кінці лот лишається за переможцем.
- **Анти-снайпінг**: ставка в останні N хвилин подовжує лот до N хвилин.
- **Адмін-панель**: бачить усіх учасників з телефонами, позначає однакові номери в різних акаунтах, може **анулювати ставку** (лідером автоматично стає попередній учасник) і **заблокувати учасника**.

Перед завершенням зателефонуйте лідерам з великими ставками. Якщо номер не відповідає, ставку можна анулювати.

## Налаштування лота

У формі лота: назва, опис, до 6 фото (стискаються автоматично), стартова ціна, мінімальний крок, максимальне підвищення за раз, дата й час завершення, подовження (хв) і прапорець «приховати» для чернеток.

## Після аукціону

У блоці «Підсумки» адмін-панелі є переможці з телефонами та кнопка «Копіювати підсумки». Щоб прибрати аукціон, вимкніть GitHub Pages для репозиторію або приховайте лоти.
